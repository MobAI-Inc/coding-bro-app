# Texas Hold'em implementation references

The Coding Bro Hold'em engine and UI were written specifically for this project.
No third-party gameplay source file is copied into this directory.

- `aaronrs2002/texas-holdem` — MIT License. Reviewed as a reference for the
  browser-table flow and the preflop/flop/turn/river presentation sequence.
  <https://github.com/aaronrs2002/texas-holdem>
- `Sukhmai/poker-evaluator` — ISC License. Reviewed to confirm the expected
  five-to-seven-card evaluator API surface and hand-category coverage. Coding
  Bro uses its own combination-based evaluator implementation.
  <https://github.com/Sukhmai/poker-evaluator>
- Kenney Playing Cards Pack — CC0 1.0. Reused for the visible playing-card PNG
  assets already stored in `src/assets/games/kenney-playing-cards`.
  <https://kenney.nl/assets/playing-cards-pack>
