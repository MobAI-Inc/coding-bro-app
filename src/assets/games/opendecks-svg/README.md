# OpenDecks SVG Playing Cards

This directory contains the 52 standard playing-card faces and two card backs
from **OpenDecks — Public Domain and CC0 Playing Cards**.

- Source: <https://github.com/AustinGabriel/OpenDecks-Public-Domain-and-CC0-Playing-Cards>
- Source revision: `0311b769090eaca2bd9b49de9d4480c1bba5f976`
- Author/curator: Austin Gabriel and the public-domain creators credited by
  OpenDecks
- License: Creative Commons Zero 1.0 Universal / public domain
- Retrieved: 2026-08-26
- Files used: 52 SVG card fronts and the blue/red SVG card backs

The upstream filenames were normalized from `ace of spades.svg` to
`spades-ace.svg` (and equivalently for every suit/rank) for deterministic
runtime lookup. Artwork content is otherwise unchanged. The upstream CC0 legal
text is preserved verbatim in `LICENSE-CC0-1.0.txt`.

OpenDecks' README explicitly permits commercial use and redistribution without
attribution. This provenance note is retained voluntarily so future maintainers
can audit the asset source.
